# 방과후 출석부 점검기

근무상황목록과 방과후 출석부를 올리면, 수업 날짜가 다음과 겹치는지 자동으로 점검하는 웹 앱입니다.

- 주말
- 학사일정상 휴일 (공휴일, 재량휴업일, 방학)
- 담당 교사의 근무상황 (연가, 조퇴, 외출, 출장 등. 결재 취소·삭제된 건은 제외)

## 사용법

1. `index.html`을 브라우저로 열거나, GitHub Pages로 배포한 주소에 접속합니다.
2. **근무상황목록**: 업무포털(나이스)에서 내려받은 엑셀(.xlsx/.xls/.csv)을 올립니다.
3. **방과후 출석부**: 엑셀 또는 글자가 있는 PDF를 올립니다. '날짜' 행에서 수업일을 읽습니다. 스캔한 PDF는 날짜를 직접 입력합니다.
4. 필요하면 강좌별 수업 시간을 입력합니다. 시간을 적으면 조퇴처럼 몇 시간짜리 근무상황은 시간이 겹칠 때만 문제로 표시합니다.
5. 결과를 엑셀로 저장하거나 표를 복사합니다.

파일은 브라우저 안에서만 읽으며 서버로 전송하지 않습니다.

## 학사일정 휴일 바꾸기

기본값은 2026학년도 포천여중 학사일정입니다. 앱 화면의 '학사일정상 휴일'에서 고치거나, `index.html`의 `DEFAULT_HOLIDAYS`를 수정하세요. 형식은 한 줄에 `YYYY-MM-DD 이름` 또는 `YYYY-MM-DD~YYYY-MM-DD 이름`입니다.

## 배포 (GitHub Pages)

Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
비공개 저장소에서 Pages를 쓰려면 GitHub Pro 이상이 필요합니다. 무료 계정이면 저장소를 공개로 바꾸거나 Netlify·Vercel 같은 정적 호스팅에 `index.html`을 올리면 됩니다.

외부 라이브러리: SheetJS (xlsx 0.18.5), PDF.js 3.11.174 (cdnjs에서 불러옴)
